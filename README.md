# GreenTech Solutions Final Project

## Project Description

GreenTech Solutions is a multi-page responsive website designed for a fictional environmental sustainability and technology company. The website promotes eco-friendly technology solutions that help businesses reduce their carbon footprint through innovative products and services.

The website was developed using HTML5, CSS3, and JavaScript while following modern web design principles, accessibility standards, and responsive design techniques.

## Features

### HTML Features
- Semantic HTML5 structure
- Navigation bar on every page
- Multiple web pages
- Images with alt text
- Contact form
- Product comparison table
- Lists and sections

### CSS Features
- External stylesheet
- Responsive mobile-friendly layout
- Green and earthy color palette
- Flexbox layouts
- Hover effects and styling

### JavaScript Features
- Interactive button alert
- Contact form validation
- Dynamic user interaction

### Accessibility Features
- Alt text for all images
- High color contrast
- Keyboard focus outlines
- Responsive typography and layout

## Accessibility

The website follows Web Content Accessibility Guidelines (WCAG) by:
- Using semantic HTML
- Providing alt text for images
- Maintaining readable color contrast
- Supporting keyboard navigation
